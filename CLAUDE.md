# CLAUDE.md - Agent Instructions for Plandroid

This file provides instructions for AI agents working on this project.

## Project Overview

**Plandroid** is a reference application demonstrating how to package a pure HTML/JS web application for Android Play Store using command-line tools only (no Android Studio).

The application is a multiplayer trivia game (1-4 players) with:
- 1000 questions in 4 languages (EN, FR, ES, DE)
- Wrong answer penalty (1s lockout)
- Winner celebration animation
- Responsive typography

## Code Style Guidelines

### JavaScript

- **No frameworks** - Pure vanilla JavaScript only
- **ES6+ syntax** - Use `const`/`let`, arrow functions, template literals
- **Module pattern** - Each .js file is a self-contained module
- **No build step** - Code runs directly in browser (no Webpack/Babel)

```javascript
// GOOD
const players = [];
const addPlayer = (name) => players.push({ name, score: 0 });

// BAD - avoid var, function declarations for simple functions
var players = [];
function addPlayer(name) { ... }
```

### CSS

- **No preprocessors** - Plain CSS only
- **CSS custom properties** for theming
- **Mobile-first** - Design for phone screens
- **Touch-friendly** - Min 44px tap targets

```css
/* GOOD - use CSS variables */
:root {
  --color-primary: #6366f1;
  --color-correct: #22c55e;
  --color-wrong: #ef4444;
}

.button {
  background: var(--color-primary);
  min-height: 44px; /* Touch target */
}
```

### HTML

- **Semantic elements** - Use `<main>`, `<section>`, `<button>`
- **Accessibility** - Include `aria-labels` where needed
- **Single file** - All screens in one `index.html` with show/hide

## Key Implementation Details

### i18n System

Language files are in `src/i18n/{lang}.json`. Load the appropriate file based on:
1. localStorage preference (if user manually selected)
2. `navigator.language` (auto-detect)
3. Default to 'en'

```javascript
// Language detection
const supportedLangs = ['en', 'fr', 'es', 'de'];
const browserLang = navigator.language.slice(0, 2);
const lang = supportedLangs.includes(browserLang) ? browserLang : 'en';
```

### Questions Format

Questions are in `src/data/questions.json`:

```json
{
  "id": 1,
  "category": "science",
  "question": {
    "en": "What planet is known as the Red Planet?",
    "fr": "Quelle planète est la planète rouge?"
  },
  "answers": {
    "en": ["Mars", "Venus", "Jupiter", "Saturn"],
    "fr": ["Mars", "Vénus", "Jupiter", "Saturne"]
  },
  "correct": 0
}
```

**Important**: Keep answers SHORT (≤15 characters) for readability.

### Game State

The game tracks:
- Player scores
- Total response time per player (for tiebreaking)
- Lockout state (1-second penalty for wrong answers)

### Wrong Answer Penalty

When a player answers incorrectly:
1. Play `wrong.mp3` sound
2. Show red overlay on their zone (opacity 0.7)
3. Disable their button for 1 second
4. Fade out overlay over 1 second
5. Re-enable button

### Winner Logic

```
1. Most correct answers wins
2. If tied: fastest total response time wins
3. If still tied: both declared winners
```

## Common Tasks for Agents

### Adding a New Question

1. Edit `src/data/questions.json`
2. Add question object with all 4 language translations
3. Ensure answers are ≤15 characters
4. Set `correct` index (0-3)

### Adding a New UI String

1. Add key to ALL language files in `src/i18n/`
2. Use `{{placeholder}}` for dynamic values
3. Update code to use the new key

### Changing the Theme

1. Edit CSS variables in `src/css/styles.css`
2. Update `:root` section with new colors
3. Test on multiple screen sizes

### Building for Play Store

1. Create signing keystore (if not exists)
2. Configure signing in `android/app/build.gradle`
3. Run `./gradlew bundleRelease`
4. Upload AAB to Play Console

## Troubleshooting

### "Command not found: cap"

```bash
npm install @capacitor/cli @capacitor/core
npx cap --version  # Use npx prefix
```

### "ANDROID_HOME not set"

```bash
# Add to ~/.bashrc or ~/.zshrc
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
```

### "Gradle build failed"

```bash
# Clean and rebuild
cd android
./gradlew clean
./gradlew assembleDebug
```

### "SDK not found"

```bash
# Verify SDK installation
sdkmanager --list
# Install missing components
sdkmanager "platforms;android-33"
```

### Sound not playing on mobile

- Sounds require user interaction first (browser policy)
- Ensure sounds are triggered by tap events
- Check file paths are correct (case-sensitive)

## Do's and Don'ts

### DO

- Keep JavaScript vanilla (no frameworks)
- Keep answers short (≤15 chars)
- Test on mobile screen sizes
- Use CSS variables for colors
- Support all 4 languages for any new text

### DON'T

- Add npm packages unless absolutely necessary
- Use Android Studio (CLI only)
- Add long answer options
- Forget to sync after web changes (`npx cap sync`)
- Break offline functionality (no external API calls)
